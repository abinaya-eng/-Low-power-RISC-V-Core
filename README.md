**Revital-X CoreRV**

![Core](Designs/NEW_CORE.png)
CoreRV is a lightweight, synthesizable 32-bit RISC-V processor core developed as part of the Revital-X SoC project. The design focuses on simplicity, scalability, and industry-oriented RTL development practices while maintaining compatibility with the RISC-V RV32IM instruction set architecture.

# -Low-power-RISC-V-Core
Developing a 5-stage RV32IM RISC-V processor with instruction-aware clock gating and operand isolation for dynamic power reduction. Verifying the optimized RTL using SystemVerilog and targeting synthesis with Cadence Genus. Planning physical implementation using Cadence Innovus and comparison with a baseline design for power, area, and frequency
